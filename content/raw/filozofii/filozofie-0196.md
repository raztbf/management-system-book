O listă de minciuni pe care societatea le spune copiilor:

- Le spunem că **adevărul învinge întotdeauna**, când istoria este plină de minciuni care au câștigat pentru mult timp.
- Le spunem că **oamenii învață din istorie**, dar generație după generație repetă aceleași greșeli.
- Le spunem că **oamenii sunt raționali**, deși rațiunea este una dintre cele mai rare calități în rândul majorității.
- Le spunem că **oamenii fac rău pentru că sunt răi**, nu pentru că își imaginează că fac bine.
- Le spunem că **ideologiile ne unesc**, când ele adesea ne separă.
- Le spunem că **dreptatea este clară**, deși realitatea este plină de zone gri.
- Le spunem că **nonviolența este ușoară**, când adevărata nonviolență cere o forță interioară rară.
- Le spunem că **dacă muncesc mult vor reuși**, când realitatea este mult mai nedreaptă și mai aleatorie.
- Le spunem că **trebuie să fie mai buni decât ceilalți**, când adevărata luptă este să fie mai buni decât ei înșiși.
- Le spunem că **viața este o competiție clară**, când de multe ori nici nu știm regulile jocului.
- Le spunem că **dacă oamenii s-ar cunoaște mai bine, s-ar iubi**, când uneori cunoașterea produce și mai multă ură.
- Le spunem că **dacă spui adevărul vei fi apreciat**, dar uneori adevărul devine un act revoluționar.
- Le spunem că **oamenii își cunosc propriile motive**, când adesea suntem străini chiar de noi înșine.
- Le spunem că **dragostea rezolvă totul**, când iubirea în exces poate distruge la fel de ușor.
- Le spunem că **cei care iubesc nu mint**, când îndrăgostiții mint, adesea, cel mai mult.
- Le spunem că **familiile fericite sunt un model universal**, când fiecare familie nefericită este nefericită în felul ei.
- Le spunem că **timpul vindecă toate rănile**, când, de multe ori, el doar le acoperă cu cicatrici.
- Le spunem că **suferința dispare**, când, de fapt, ea devine parte din cine suntem.
- Le spunem că **suntem liberi**, când suntem, adesea, dominați de tribul din care facem parte.
- Le spunem că **egalitatea este un fapt**, când, în realitate, este mai mult o aspirație.
- Le spunem că **speranța este mereu bună**, deși uneori ea prelungește suferința.
- Le spunem că **viitorul va fi mai bun**, deși fiecare generație trebuie să lupte din nou pentru asta.
- Le spunem că **totul se rezolvă la final**, deși viața nu este o poveste cu final moral.
- Le spunem că **adulții știu ce fac**, când de multe ori improvizează.
- Le spunem că **odată ce crești nu mai ești vulnerabil**, când maturitatea înseamnă tocmai acceptarea vulnerabilității.
- Le spunem că **fericirea este scopul**, când uneori scopul este doar să mergi mai departe.
- Le spunem că **viața este dreaptă**, când, de multe ori, este doar viață.

Știu că aceste minciuni nu sunt spuse din răutate. Le spunem pentru a proteja. Întrebarea care rămâne este... pe cine protejăm... pe noi sau pe ei?
