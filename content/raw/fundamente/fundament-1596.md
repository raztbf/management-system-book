Cea mai proastă consecință pentru un om care nu performează este să lucreze mai mult.

Să spunem că am un grădinar care îmi taie florile și udă buruienile. La finalul săptămânii, fac o evaluare și realizez că îmi distruge grădina.

Acum...

Ce se va întâmpla dacă îi cer să stea peste program sau să vină și sâmbăta?

Îmi va distruge grădina mai repede.

Avem nevoie să identificăm corect problema pentru a veni cu o soluție bună. Dacă problema este lipsa abilităților, consecința este instruirea. Dacă problema este lenea, atunci consecința este programul prelungit. Dacă problema este caracterul, atunci consecința este angajarea omului de către concurență.
