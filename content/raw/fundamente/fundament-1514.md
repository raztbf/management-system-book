Motivul pentru care cumpărătorii aleg liderii de piață este că sunt cea mai puțin riscantă opțiune.

Asta este problema cu care te confrunți în vânzări atunci când nu ești lider de piață.

Normal că majoritatea aleg să rezolve această problemă prin scăderea prețurilor. Și este adevărat că un preț mai mic înseamnă un risc mai mic. Doar că trebuie să găsești acel preț care întoarce roata și face omul să spună că prețul mai mic merită cu adevărat riscul de a nu lucra cu liderul.

De multe ori, acel preț este unul la care compania nu mai este profitabilă.

Problema este că mulți uită că scăderea prețului nu este singura modalitate de a scădea riscul. Garanțiile sunt o altă opțiune. Înlocuirea este o altă opțiune. Plata după rezultat este o altă opțiune. Demonstrația este o altă opțiune. Scăderea prețului este doar cea care necesită cel mai puțin efort de gândire.
