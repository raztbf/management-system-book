Una dintre marile greșeli pe care le observ la start-upuri este că recrutează un singur vânzător la început.

Atunci când construiești prima echipă de vânzări, dacă angajezi un singur om și nu performează, nu știi exact unde este problema.

- Omul nu este bun?
- Produsul este greu de vândut?
- Scriptul este prost?
- Lead-urile sunt slabe?
- Prețul este greșit?

Dar dacă angajezi doi oameni în același timp... poți compara. Dacă unul vinde și celălalt nu, problema este probabil la persoană. Dacă amândoi nu vând, problema este la sistem: ofertă, lead-uri, training, poziționare, proces, preț sau produs.

Una dintre întrebările critice pe care trebuie să ni le punem ca antreprenori este: Dacă nu va funcționa, vom putea să identificăm cauza?

Asta este ceea ce creează un sistem care evoluează, față de unul care rămâne blocat.
