# Default Agreements as Exclusive Dealing (antitrust comportamental)

## Ce spune (abstract)

Lucrarea analizează exact mecanismul descris de Răzvan: concentrarea mare a multor piețe digitale, precum CĂUTAREA și PUBLICITATEA, se datorează parțial exploatării INERȚIEI oamenilor. O teorie care a câștigat tracțiune: acordurile de a seta o aplicație drept DEFAULT pentru utilizatori echivalează cu aranjamente de exclusivitate, fiindcă oamenii tind să rămână pe status quo. Testează empiric (2 experimente + synthetic control): efectele de default există pentru aplicații digitale, dar mărimile variază. Susține teza monopolului prin default: parteneriatele de tip „motor implicit" (ex. Google-Apple) susțin dominanța prin inerția utilizatorilor.
