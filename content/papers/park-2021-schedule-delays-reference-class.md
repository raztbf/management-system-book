# Park (2021) — Schedule Delays of Major Projects

## Ce spune (abstract)

Studiul investighează frecvența, magnitudinea și caracteristicile întârzierilor de program la 113 achiziții
publice mari (SUA și UK, 1999–2018). Constatare: există o prăpastie între presupuneri și realitate — în
ciuda eforturilor extinse de control al proiectelor în ultimele două decenii, performanța de program NU s-a
îmbunătățit deloc. Pentru a aborda problema, studiul sugerează REFERENCE CLASS FORECASTING pentru a dezvolta
estimări de program mai realiste și mai fiabile.
